# Mechanical Domain — Six-Layer Stack

**Effort:** Force (F) / Torque (τ) · **Flow:** Velocity (v) / Angular velocity (ω) · **Power:** F × v, τ × ω

## 1. Vocabulary

Force · Torque · Velocity · Angular velocity · Displacement · Angle · Stiffness · Compliance · Mass · Moment of inertia · Damping · Natural frequency · Damping ratio · Resonance · Backlash · Mechanical hysteresis · Friction regimes (static, Coulomb, viscous, Stribeck) · Stress · Strain · Young's modulus · Fatigue · Flexure · Kinematic constraint.

Key relations: mẍ + cẋ + kx = F(t) · ωₙ = √(k/m) · ζ = c / (2√(km)) · Q = 1/(2ζ).

| Bearings | 52100 steel, Si₃N₄, bronze |
| Reference | Granite, Zerodur, Invar, fused silica |
| Damping | Viscoelastic polymer, lead |

## 5. Technique

| Function | Technique |
|---|---|
| Structural | Casting, forging, machining |
| Stiffness/weight | Autoclave lay-up, HIP, lapping |
| Springs/flexures | Heat treatment, waterjet, wire EDM |
| Bearings | Grinding, honing, superfinishing |
| Reference | Grinding, lapping, scraping |
| Damping | Lamination, molding |

Precision techniques: grinding and lapping (sub-micron flatness) · scraping (reference surfaces to <1 µm) · waterjet and wire EDM (cut hardened materials without heat damage).

## 6. Features

| Function | Feature |
|---|---|
| Structural | Strength, stiffness |
| Stiffness/weight | High specific stiffness |
| Springs/flexures | Zero backlash |
| Bearings | Low friction |
| Reference | Dimensional stability |
| Damping | Vibration isolation |

Design patterns: flexures (zero backlash, no stiction, no wear; limited stroke) · kinematic mounts (six-point exact constraint) · preloaded bearings · damping treatments (constrained-layer, tuned mass dampers).
