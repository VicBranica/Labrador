# Fluidic Domain — Six-Layer Stack

**Effort:** Pressure (P) · **Flow:** Volumetric flow (Q) · **Power:** P × Q

## 1. Vocabulary

Pressure (gauge/absolute/differential) · Volumetric flow · Mass flow · Density · Viscosity · Reynolds number · Bernoulli's principle · Head · Compressibility · Bulk modulus · Cavitation · Hydraulic circuit · Servo valve · Accumulator · Orifice.

| Electrical | Fluidic |

| Voltage | Pressure |
| Current | Volumetric flow |
| Resistance | Orifice restriction |
| Capacitance | Accumulator |
| Inductance | Fluid column inertia |

## 2. Measurement

| Year | Who | Instrument | What it saw |
|---|---|---|---|
| 1647 | Pascal | Torricellian barometers | Pressure transmission; altitude variation |

| 1795 | Bramah | Hydraulic press + gauge | Force multiplication |
| 1883 | Reynolds | Glass pipe with dye | Laminar vs. turbulent |
| 1951 | Tinsley/Moog | Flow bench, LVDTs | Spool position, flow response |

## 6. Features

| Function | Feature |
|---|---|
| Cylinders | High pressure, long life |
| Spools/pistons | <1 µm clearance |
| Static seals | Pressure containment |
| Dynamic seals | Low friction |
| Fluids | Lubricity, fire resistance |
| Diaphragms | Chemical resistance |

| Property | Hydraulic | Pneumatic |
|---|---|---|
| Compressibility | Low | High |
| Bandwidth | 10–1000 Hz | 10–100 Hz |
| Force density | Very high | Medium |
| Compliance | Stiff | Soft |
| Typical use | Heavy machinery, aircraft | Automation, grippers |

Two-stage flapper-nozzle servo valves give precision force/position control up to ~500 Hz.
