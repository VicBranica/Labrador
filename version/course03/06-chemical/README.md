# Chemical Domain — Six-Layer Stack

**State variable:** Concentration / activity · **Note:** does not fit the clean effort × flow pattern

## 1. Vocabulary

Concentration · Activity · pH · Electrode potential · Reference electrode · Nernst equation · Diffusion-limited current · Amperometric / potentiometric · Selectivity · Sensitivity · Limit of detection · Enzyme kinetics (Km, Vmax) · Fuel cell · Electrolysis.

Key relation: E = E° − (RT / nF) · ln(Q) — ~59 mV per decade at 25 °C, n = 1.

## 2. Measurement

| Year | Who | Instrument | What it saw |
|---|---|---|---|
| 1800 | Volta | Voltaic pile, electroscope | Steady current from pile |
| 1834 | Faraday | Electrolytic cell, balance | Mass deposited per unit charge |
| 1839 | Grove | Pt electrodes in dilute H₂SO₄ | Current from H₂/O₂ cell |
| 1889 | Nernst | H₂ electrode, salt bridges | EMF vs. concentration |
| 1909 | Sørensen | H₂ electrode, calomel reference | H⁺ activity |
| 1956 | Clark | Pt cathode behind polymer membrane | Dissolved O₂ as diffusion current |
| 1962 | Clark & Lyons | Clark electrode + enzyme membrane | Glucose via O₂ consumption |

## 4. Material

| Function | Material |
|---|---|
| Electrodes | Pt, Au, Ag/AgCl, glassy C |
| pH membrane | Lithium silicate glass |
| ISE membranes | PVC + ionophore; LaF₃ crystal |
| MOS gas sensors | SnO₂, ZnO, WO₃ |
| Biosensor layers | Enzymes, antibodies |
| Fuel-cell catalyst | Pt, Pt/Ru |

## 5. Technique

| Function | Technique |
|---|---|
| Electrodes | Electroplating, screen-printing |
| pH membrane | Glass blowing, hydration |
| ISE membranes | Casting, crystal growth |
| MOS gas sensors | Screen-print, sol-gel |
| Biosensor layers | Immobilization (SAM, crosslink) |
| Fuel-cell catalyst | Impregnation on Nafion |

## 6. Features

| Function | Feature |
|---|---|
| Electrodes | Stable, catalytic |
| pH membrane | Nernstian H⁺ response |
| ISE membranes | Species-selective |
| MOS gas sensors | Low cost, broad |
| Biosensor layers | Target-specific |
| Fuel-cell catalyst | High activity |

Sensor families: potentiometric (pH, ISEs) · amperometric (Clark electrode, glucose) · conductometric · metal-oxide semiconductor (SnO₂, hot) · optical (colorimetric strips, fluorescent probes).
