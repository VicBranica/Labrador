# Radiant Domain — Six-Layer Stack

**State variable:** Photon flux · **Note:** does not fit the clean effort × flow pattern

## 1. Vocabulary

Photon · Wavelength / frequency · Intensity · Radiance · Spectrum · Polarization · Coherence · Diffraction · Interference · Refraction · Refractive index · Reflection / absorption / transmission · Beer–Lambert · Quantum efficiency · Responsivity · Dark current · NEP · Bandgap · Blackbody · Emissivity · Interferometry.

Key relations: E_photon = hν = hc/λ · a detector responds when E ≥ E_g (bandgap); longer wavelengths need smaller bandgaps (Si → Ge → InGaAs → HgCdTe).

## 2. Measurement

| Year | Who | Instrument | What it saw |
|---|---|---|---|
| 1801 | Young | Sun + pinhole + slits | Fringe spacing |
| 1887 | Michelson | Michelson interferometer | Fringe shift |
| 1905 | Einstein | Lenard's tube, electrometer | Photoelectric threshold |
| 1960 | Maiman | Ruby rod, flashlamp, photodiode | 694 nm pulse from ruby |
| 1962 | Holonyak | Spectrometer, probe station | Red light from GaAsP |
| 1969 | Boyle & Smith | Oscilloscope, pulse gens | Charge shift across MOS caps |
| 1986 | Ashkin | Lasers, high-NA microscope | Trapping force on microspheres |
| 1990s | Nakamura et al. | MOCVD, integrating spheres | GaN electroluminescence |

## 4. Material

| Function | Material |
|---|---|
| Photodetectors | Si, InGaAs, Ge, HgCdTe, InSb, GaN |
| Image sensors | Si + color filter + microlens |
| LEDs | GaN/InGaN, AlGaInP, GaAs |
| Laser diodes | GaAs/AlGaAs, InGaAsP, GaN |
| Solid-state lasers | Nd:YAG, Yb:YAG, Ti:sapphire |
| Fiber | Fused silica, ZBLAN |
| Optics | Fused silica, sapphire, ZnSe, Ge, CaF₂ |
| Coatings | Al, Ag, dielectric stacks |

## 5. Technique

| Function | Technique |
|---|---|
| Photodetectors | Epitaxy, ROIC bonding |
| Image sensors | CMOS fab, filter lithography |
| LEDs | MOCVD + phosphor coating |
| Laser diodes | Heterostructure epitaxy + cleaved facets |
| Solid-state lasers | Crystal growth + diode pump |
| Fiber | Preform drawing, MCVD |
| Optics | Grinding, polishing, MRF, diamond turning |
| Coatings | Vacuum deposition |
