# Magnetic Domain — Six-Layer Stack

**Effort:** MMF (N·I) · **Flow:** dΦ/dt · **Circuit law:** MMF = ℛΦ, with ℛ = l / (μA)

## 1. Vocabulary

Magnetic field (H) · Magnetic flux (Φ) · Flux density (B) · Permeability (μ, μᵣ) · Reluctance (ℛ) · Magnetomotive force (MMF) · Magnetic circuit · Electromagnet · Permanent magnet · B–H curve · Hysteresis · Saturation · Remanence (Bᵣ) · Coercivity (Hc) · Energy product (BHmax) · Eddy currents · Lorentz force · Hall effect · GMR / TMR · Air gap.

| Electrical | Magnetic |
|---|---|
| Voltage (V) | MMF (N·I) |
| Current (I) | Flux (Φ) |
| Resistance (R) | Reluctance (ℛ) |
| V = IR | MMF = ℛΦ |

## 2. Measurement

| Year | Who | Instrument | What it saw |
|---|---|---|---|
| 1820 | Ørsted | Pile + wire + compass | Compass deflection beside current |
| 1821 | Faraday | Mercury bath, magnet, suspended wire | Continuous rotation of wire + magnet |
| 1879 | Hall | Electromagnet, galvanometer | Transverse voltage on gold leaf in B-field |
| 1888 | Tesla | Polyphase alternator, prony brake | Torque of polyphase induction motor |
| 1984 | Sagawa, Croat | Vibrating-sample magnetometer | Hysteresis loop of NdFeB |
| 1988 | Fert, Grünberg | MBE chambers, cryostats, superconducting magnets | Resistance drop in Fe/Cr multilayers |

## 4. Material

| Function | Material |
|---|---|
| Soft cores | Silicon steel, permalloy, Mu-metal, ferrite, Metglas |
| Permanent magnets | **NdFeB**, SmCo, AlNiCo, ferrite |
| Hall / MR sensors | InSb, Si (Hall); permalloy (AMR); Co/Cu, Fe/Cr (GMR); MgO (TMR) |
| Electromagnets | Copper magnet wire + soft core |

## 5. Technique

| Function | Technique |
|---|---|
| Soft cores | Lamination, sintering, ribbon casting |
| Permanent magnets | Aligned-field sintering |
| Hall / MR sensors | Thin-film deposition, lithography |
| Electromagnets | Winding, varnish impregnation |

Signature techniques: silicon-steel lamination · aligned-field NdFeB sintering · thin-film multilayer deposition · rotor skewing.

## 6. Features

| Function | Feature |
|---|---|
| Soft cores | High μᵣ, low loss |
| Permanent magnets | High BHmax |
| Hall / MR sensors | Non-contact, small |
| Electromagnets | Controllable force |

Device families: DC brushed motor · BLDC · AC induction · stepper · voice coil · solenoid / electromagnet · Hall sensor · GMR / TMR · LVDT, RVDT, resolver.

Gap force: F ≈ B²A / (2μ₀) — the calculation behind every solenoid, relay, loudspeaker, and motor pole.
